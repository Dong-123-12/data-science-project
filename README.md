# Data Science Project: Exploratory Analysis of Iris Dataset

## Research Question
Can we distinguish three different iris flower species using their sepal and petal size measurements? We explore the morphological differences between species.

## Dataset Source and Usage License
The Iris dataset is built-in within scikit-learn. It is a classic public open dataset, free for academic and educational use. No private or restricted data included.

## Methods and Tools
Tools: Python, Jupyter Notebook, Pandas, Matplotlib, Seaborn
Methods: Exploratory Data Analysis (EDA), descriptive statistics, data visualisation.

## Key Findings and One Limitation
### Key Findings
1. The species *setosa* has much shorter petal length and can be easily separated from the other two species.
2. *versicolor* and *virginica* have overlapping feature values, making them harder to distinguish only by petal length.

### Limitation
The dataset only contains 150 samples. The small sample size limits the generalisation to real-world wild iris populations.
